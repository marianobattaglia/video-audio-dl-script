# video-audio-dl

Scripts locales para descargar MP4 o MP3 usando `yt-dlp`.

## Windows
Doble click en `descargar_windows.ps1`.

## macOS
Doble click en `descargar_macos.command`.

## Requisitos
- `yt-dlp` instalado y disponible en PATH.
- `ffmpeg` instalado (necesario para MP3).

## Instalacion

Windows (PowerShell):
```
winget install yt-dlp.yt-dlp
winget install Gyan.FFmpeg
```

macOS (Homebrew):
```
brew install yt-dlp ffmpeg
```
